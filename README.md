# Solana Field Manual

Short technical guides about Solana for people starting from zero.

**Website:** https://josephinney.github.io/solana-field-manual/

`solana` `blockchain` `anchor` `rust` `education` `tutorial` `github-pages`

> Educational content. This is not financial advice and is not affiliated with the Solana Foundation.

## What it covers

| # | Guide |
|---|---|
| 00 | Centralized vs decentralized |
| 01 | What is Solana |
| 02 | Tokens on Solana |
| 03 | Create a token |
| 04 | Wallets and keys |
| 05 | Transactions and fees |
| 06 | Validators and staking |
| 07 | Programs |
| 08 | Your first program with Anchor |
| 09 | Writing safer programs |
| 10 | Two paths: consensus or applications |

Each guide covers a single topic in plain technical language. They include diagrams, the output you will see in the terminal when a command is involved, and hands-on parts that run on devnet, Solana's test network. A glossary collects every term in one place.

## Found an error?

Solana changes quickly. If something is out of date or wrong, use the *open an issue* link at the bottom of any page, or open an issue in this repository.
