SOLANA FIELD MANUAL

Solana Field Manual is a set of short technical guides about Solana for people who are starting from zero. You do not need to know anything about blockchains or programming to begin. Each guide covers a single topic, explains it in plain technical language and ends when the topic is covered.

The guides start with the idea behind decentralized networks and what makes Solana different. Then they move to the pieces you deal with every day: accounts, tokens, wallets and keys, transactions and fees, and the validators that keep the network running. From there they go into programs, the code that runs on Solana. You write, test and deploy your first one with Anchor, and then learn the checks that keep a program safe. The last guide describes the two directions you can take once you know the basics.

Every guide includes diagrams, and when a command is involved you see what the terminal prints, so you know what to expect before you run it. The hands-on parts use devnet, Solana's test network, where SOL has no value and mistakes cost nothing. Facts that change over time, such as fees or network parameters, were checked against official sources on the date shown in each guide, and the glossary collects every term in one place.
